# xilcmd.github.io

Source for the [xilcmd.github.io](https://xilcmd.github.io/) landing page: a single static
`index.html` describing **xil-pipeline**, the markdown-script-to-broadcast-audio tool, and its
two implementations.

## What's here

Just a static page — no build step. GitHub Pages serves `index.html` directly (`.nojekyll`
disables Jekyll processing).

## Related repos

- [xilcmd/xil-pipeline](https://github.com/xilcmd/xil-pipeline) — the Python reference implementation
- [xilcmd/rxil-pipeline](https://github.com/xilcmd/rxil-pipeline) — the Rust port
